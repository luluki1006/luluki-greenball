❓ 常见问题

通义千问提示"未实名 / 无额度"？

先完成阿里云个人实名认证，再去百炼首页领取免费额度（90天）。领取后稍等片刻再试。务必开启「用完即停」。

会扣我钱吗？

不会。通义千问的免费额度 90 天内有效，且你已开启「用完即停」，额度耗尽即停止，零费用。拍照识别几个植物调用量极小。

Key 泄露了怎么办？

百炼控制台删除旧 API Key，新建一个，然后回 App 设置更新即可。旧 Key 立即失效。

换了手机 / 重装 App，Key 还在吗？

Key 存在本机浏览器里，换手机或清除站点数据会丢失，需要重新在「设置」里填一次。建议把 Key 存进手机备忘录备份。

天气要怎么弄？

不用申请任何 Key。打开 App →「⚙️ 设置」→ 点「📍 定位」允许定位权限，或用首页的「📍 点此开启定位」。也可以手动填城市名（如"北京"）。天气与浇水提醒立即生效。
